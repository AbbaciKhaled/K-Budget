# Security policy

K-Budget handles personal financial data, so security reports are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Instead, report it privately through GitHub:
_Security_ tab of this repository → **Report a vulnerability**.

Include what you found, the steps to reproduce it and the impact you expect. You'll get an answer as soon as
possible; once a fix is released, you can be credited if you wish.

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Scope

In scope: this application's code (authentication, access control between users and shared categories,
data validation, server actions).

Out of scope: vulnerabilities in your own hosting or database configuration, and denial of service by volume.
